# 猫爪印记 · 午后的小房间

轻松的猫咪滑行解谜游戏，20关、休闲探索与限步挑战、15～20关高难度入口。软垫让猫停下转向，铺满地板后停在猫窝获胜。支持撤销、提示、独立存档、音乐与通关庆祝。

**在线游玩：[打开游戏](https://zhangxueyi169.github.io/game-for-test/)**

首次点击后播放音乐；右上角可静音。存档保存在当前浏览器，清除网站数据会清除记录。没有服务端账号或排行榜。

## 本地运行

使用Node.js 22：

```sh
npm ci
npm run dev
```

验证与构建：

```sh
npm test
npm run levels:validate
npm run build
npm run preview
```

不要直接双击源码index.html。需要离线单文件可运行 `npm run build:offline`，生成output目录下的HTML。

## 部署

GitHub Pages设置使用GitHub Actions。推送main后，工作流依次安装依赖、运行规则和20关验证、构建dist并发布。相对资源路径支持 `/game-for-test/` 子路径。

## 资产与验证范围

角色、主题背景和道具使用OpenAI内置image_gen制作；原始图像保留在assets/production。背景音乐及音效为本项目原创编曲/程序合成，不是真猫录音，不含外部音乐采样。烟花、爪印、动画变换与界面由程序绘制。此仓库不包含面试PDF、参考图和本地生成提示词中的机器路径。

20关已通过同一规则求解器的最短解证明，探索/挑战全部逐关浏览器回放通过。已有Edge移动视口、触控模拟、资源失败、存储失败与音频生命周期检查；详细报告位于docs/qa。未完成真实手机上的完整流程和真人难度校准，不将模拟结果当作真机验收。

图片为高分辨率母版，首开资源较大；首次加载时间取决于网络与设备。GitHub Pages在不同网络下的可达性可能不同。
